Privacy Policy

Last updated: October 23, 2026 · Contact: ljingjian007@gmail.com

This policy describes the local Video Release application and this informational website. Video Release is intended for the operator's own channels and other channels the operator is authorized to manage.

本政策说明发布助手使用 Google / YouTube 数据的方式。发布服务运行在使用者本机，本网站仅用于介绍应用和展示政策。

1. Information the application uses

  • Channel information: channel ID, channel name, and handle, used to identify and verify the destination of a task.
  • Authorization credentials: OAuth access and refresh tokens, used to make authorized Google API requests. The application does not ask for or store your Google password.
  • Video and task information: a selected local file, its path and file attributes, title, description, visibility, audience declaration, AI content declaration, task progress, video ID, and result link.
  • Video and channel data: supported statistics and, when you authorize it, YouTube Analytics report data such as views and watch time.
  • Optional browser configuration: operator-entered account email, browser window and profile information, and task-related browser evidence.

2. How information is used

The application uses this information to identify your selected channel, upload a video you submit, check processing and visibility, display results, recover an existing upload, and display supported performance data. It requests upload access, YouTube account read access, and Analytics read access. Monetary Analytics permission is not requested.

Video Release's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

3. Storage and data flows

OAuth credentials are saved in files on the computer where the publisher is installed. The current application restricts its credential directory and files to the local operating-system user. Credentials are excluded from the application's Git source and are not returned to the publishing page.

Task records and collected statistics are stored in local application files. The selected video is read from its local path and transmitted to Google/YouTube when you submit an API upload. OAuth requests and token refreshes are sent to Google. Your operating system, local backups, other software with access to your user account, and any enabled browser services can affect the confidentiality of locally stored information.

If you choose the optional Codex/browser workflow, task instructions can include video metadata, a local file path, and the selected channel or browser identity. These instructions are sent to the configured Codex service, and browser interactions may be processed according to that service's policies. This workflow is distinct from direct API uploads. The application does not intentionally include OAuth credential files in those instructions.

4. Sharing and AI use

The application sends data to Google and YouTube as needed for authorized API functions, and to the configured Codex/browser services when you select that workflow. It does not operate a separate developer-hosted upload or analytics backend. Google user data is not sold, used for targeted advertising, or used by Video Release to develop or train generalized AI or machine-learning models. Third-party services are governed by their own applicable policies, including the Google Privacy Policy.

A support message you choose to send to the developer can contain information you include in that message. Do not send passwords, access tokens, refresh tokens, or private video files in support email.

5. Retention, deletion, and revocation

Local task records, upload receipts, and credentials remain on the installed computer until they are removed or replaced by its operator. The current application does not provide an automatic timed deletion schedule. To remove local data, stop the publisher and remove the corresponding local task data and credential files; copies in your backups must be managed separately. You can contact the developer for help identifying the files without sending their contents.

You can revoke Google account access in Google Account third-party connections. Revocation prevents further authorized requests using that grant; it does not erase existing local records. Deleting local data or revoking access does not delete videos already uploaded to YouTube. Manage or delete those videos in YouTube Studio.

6. This website

This informational website does not include analytics scripts, advertising, login forms, or upload forms. Its hosting provider may process technical access information such as visitor IP addresses for delivery and security under the provider's privacy policy. When hosted on GitHub Pages, that processing is described in the GitHub Privacy Statement.

7. Updates and contact

This policy will be updated when the application's data practices change. The revision date appears above. For privacy or data-removal assistance, contact ljingjian007@gmail.com.
